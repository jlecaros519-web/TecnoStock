# TecnoStock
Sistema web de gestión de inventario.

## Instalación

1. Copiar la carpeta `TecnoStock` dentro de `htdocs`.
2. Iniciar Apache y MySQL en XAMPP.
3. Importar `base_datos.sql` desde phpMyAdmin.
4. La conexión está configurada para MySQL en el puerto `3306`.
5. Abrir `http://localhost/TecnoStock/login.php`.
